알아볼괘 - 심리테스트 사이트 시작 가이드
=========================================
(처음 보시는 분도 이해할 수 있도록 아주 쉽게 설명했어요)

■ 지금 이 zip 안에 뭐가 들어있나요?
- 아래 8가지 심리테스트가 전부 완성된 상태의 웹사이트 파일이에요.
  1) 나는 테토? 에겐?
  2) MBTI 간단 테스트 (16유형)
  3) 소시오패스 테스트
  4) 연애 유형 테스트
  5) 사랑의 언어 테스트
  6) 동물상 테스트
  7) 전생 테스트
  8) IQ / EQ 테스트
- 모든 테스트는 결과 화면에 "지수 %" 게이지, "천생연분 / 상극" 궁합
  카드, 결과를 이미지로 저장하는 기능까지 똑같은 형태로 들어있어요.
- 모바일 화면에 맞춰 제작했어요.
- 개인정보처리방침, 이용약관 페이지도 기본 문구로 만들어 두었어요.


1. 먼저 내 컴퓨터에서 미리보기 해보기
------------------------------------------
1) 압축을 푼 폴더 안에서 "index.html" 파일을 찾으세요.
2) 그 파일을 더블클릭하면 크롬(Chrome) 같은 브라우저에서 사이트가 열려요.
3) 실제로는 휴대폰으로 보는 게 진짜 화면이니, 브라우저 창을
   최대한 좁게 줄여서 봐 주세요. (또는 개발자모드로 모바일 화면 미리보기)
4) 아무 테스트나 눌러서 끝까지 진행해 보고, 결과 화면의 지수/궁합/
   이미지 저장 버튼이 잘 나오는지 확인해 주세요.


2. 인터넷에 실제로 올리기 (뉴스매매 사이트와 같은 방식)
------------------------------------------
이미 하고 계신 newsmeme.co.kr 사이트와 똑같이 "GitHub + Cloudflare Pages"
무료 방식으로 올리시면 돼요. 순서는 이렇게 진행하시면 됩니다.

1) GitHub 사이트(github.com)에 로그인해서 새 저장소(Repository)를
   하나 만드세요. (예: maumcatch 같은 이름)
2) 그 저장소에 이 zip 안의 파일/폴더를 전부 그대로 업로드하세요.
   (index.html, assets 폴더, tests 폴더 등 전부 다요)
3) Cloudflare 사이트(dash.cloudflare.com)에 로그인해서
   "Workers & Pages" 메뉴로 들어가세요.
4) "Create application" → "Pages" → "Connect to Git"을 눌러서
   방금 만든 GitHub 저장소를 연결하세요.
5) 빌드 설정은 그냥 기본값 그대로 두고 배포(Deploy)를 눌러주세요.
   (이 사이트는 순수 HTML이라 별도 빌드 과정이 필요 없어요)
6) 배포가 끝나면 "~~~.pages.dev" 라는 임시 주소가 생기는데,
   여기서 실제 도메인(예: maumcatch.com 같은 걸 새로 사는 경우)을
   연결하면 완성이에요.

* 만약 이 과정이 낯설게 느껴지시면, 다음 대화에서 "GitHub 업로드 도와줘"
  라고 말씀해 주세요. 화면 공유해 주시면 하나씩 같이 진행할 수 있어요.


3. 애드센스(광고) 신청 전에 꼭 확인할 것
------------------------------------------
1) privacy.html, terms.html 파일 안에 "운영자 이메일 주소를 입력해주세요"
   라고 되어 있는 부분을 실제 이메일 주소로 바꿔주세요.
2) (완료) sitemap.xml, robots.txt는 실제 도메인(arabol.co.kr)으로
   이미 반영해 두었어요.
3) 지금 테스트가 8개나 있어서 콘텐츠 부족으로 거절될 가능성은 낮지만,
   실제 도메인으로 올린 뒤 어느 정도 시간을 두고 애드센스에 신청하는
   걸 추천해요.
4) 애드센스 승인을 받으면, 광고 코드를 아래 표시된 자리에 넣으면 돼요.
   각 html 파일 안에서 이렇게 생긴 부분을 찾으시면 됩니다.
     <div class="ad-slot">광고 영역 (심사 통과 후 게재 예정)</div>
   이 부분을 구글에서 받은 광고 코드로 교체하면 광고가 나와요.


4. 나중에 다른 테스트를 더 추가하고 싶을 때
------------------------------------------
지금 있는 8개 테스트와 똑같은 틀(지수 게이지 + 궁합 + 이미지 저장)로
새 테스트를 추가할 수 있도록 구조를 만들어 두었어요. 다음 대화에서
"OO테스트도 같은 방식으로 만들어줘" 라고 요청하시면 됩니다.
(tests 폴더 안에 tests/새테스트이름 처럼 새 폴더가 하나 더 생기는 방식이에요)


5. 사이트 이름/색상을 바꾸고 싶을 때
------------------------------------------
- 사이트 이름은 "알아볼괘"로 정해서 전체 파일에 반영해 두었어요.
  이름을 또 바꾸고 싶으면 다음 대화에서 말씀해 주세요, 한 번에
  전체 파일에 반영해 드릴게요.
- 색상(보라/핑크 그라데이션)도 assets/css/style.css 파일 맨 위
  --brand-1, --brand-2 부분만 바꾸면 사이트 전체 색이 바뀌어요.


6. 참고로 알아두시면 좋은 점
------------------------------------------
- "소시오패스 테스트"와 "테토-에겐 테스트"는 초반에 만들어서 결과
  지수가 0%나 100%까지는 안 나오는 구조예요(다른 테스트들은 0~100%가
  다 나와요). 나중에 "그 두 테스트 지수도 0~100% 나오게 고쳐줘"라고
  말씀하시면 한 번에 고쳐드릴게요.
- "동물상 / 사랑의 언어 / 전생 / MBTI" 테스트는 사진이 아니라 성격
  설문으로 결과를 알려주는 방식이에요.


궁금한 점이 있으면 언제든 다음 대화에서 편하게 물어보세요!
