환경을 바꾸는 게 제일 빠릅니다

예민한 수면은 의지로 고치기 어려워요. 대신 물리적인 조건을 정리하면 체감이 확실히 달라집니다.

  • 빛 — 암막 커튼, 충전기 LED 가리기
  • 소리 — 귀마개나 일정한 백색소음
  • 온도 — 약간 서늘한 편이 잠들기에 유리합니다

20분 규칙

누워서 20분 넘게 뒤척인다면 일어나는 것이 권장돼요. 누운 채로 오래 있으면 침대가 '잠드는 곳'이라는 연결이 약해지거든요. 거실에서 조용히 있다가 졸릴 때 다시 눕는 편이 낫습니다.

이런 상태가 몇 주 이상 이어지고 낮 생활에 지장이 있다면 수면클리닉 상담을 고려해보세요. 잘 알려진 영역이고 개선 가능합니다.
